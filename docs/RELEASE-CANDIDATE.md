# v0.3.1-extended.6 · 在线玩家、房间邀请与公告草稿

基于上游 v0.3.1，上一正式扩展版为 v0.3.1-extended.5。

## 更新内容

- 首页「名博士在线」可展开本服可见在线玩家，支持姓名搜索、分页和大厅 / 房间 / 对局状态。
- 右上角可选在线、暂离、忙碌和隐身，浏览器记忆并在连接时先恢复；隐身玩家不出现在名单或可见人数中，不能发送或接收邀请。
- 房间新增直接邀请，对方确认后才加入；检查空位、阶段及玩家状态，60 秒失效，发送间隔至少 10 秒，每人最多 5 份待处理邀请。
- 控制台新增六项社交管理开关：在线名单、房间邀请、状态选择、隐身选择、可见人数、仅房主邀请，保存后即时生效。
- 每个房间可独立设置联防叠层；控制台「允许房主自行设置联防叠层」默认关闭，授权后房主可在开局前调整。最终攻势、隐秘核心仍不叠层。
- 公告新增最多 30 份服务器草稿，支持保存、载入、覆盖、另存和删除，重启后保留。提供维护、更新、房间规则、临时故障四种模板。
- 公告支持实时 Markdown 预览，和玩家端共用安全渲染。保存、模板和预览不发布，仍需主动点击发布。
- 同版补充：已发布公告默认跨重启保留，沿用原起止时间，过期或已撤下的不恢复；控制台可单独关闭，定时及直到撤下语义不变。

已安装早期 `v0.3.1-extended.6` 的用户，请重新下载更新后的附件，或在控制台选中当前版本执行「修复素材并重启」，以取得本次公告保留补充。

在线名单、邀请、状态选择、隐身选择和可见人数默认开启，仅房主邀请默认关闭；房主修改联防叠层的权限默认关闭。隐身只影响发现与邀请，共同房间中的真实席位仍可见；关闭隐身选择不会强制公开已隐身玩家。
