# v0.3.1-extended.2 · 完整素材更新与皮肤海报修复

基于上游 v0.3.1（b3deebda），上一正式扩展版为 v0.3.1-extended.1。本次为本库修复版本，未新增官方上游版本。

## 更新内容

- 控制台更新改用带签名的完整包，补齐素材、字体和清单；只写入新增或变化文件，保留相同文件与额外本机素材。程序和素材共同备份、失败回滚。
- 解压和素材哈希在工作线程执行，避免阻塞活动对局；新增「修复素材并重启」，只有 lite 附件的版本不再提供控制台安装。
- 修复皮肤选择及放大预览重复显示默认图，正确使用已有的 174 套专属海报；缺少专属图时继续回退默认图。
- 过滤单条非法皮肤偏好，避免整份同步被拒，同时保留暂不可用的合法插件选择。
- 自定义表情使用与预载一致的 CDN 地址；公告弹窗加宽，保持小屏边距与滚动。适配来源为参考站当日公开前端快照。
- Windows 后台测试与工具子进程隐藏命令窗口，移除临时诊断脚本；修复发布包文档链接指向本库扩展版本。

## 下载与升级

| 附件 | 内容 |
| --- | --- |
| Stronghold-Protocol-v0.3.1-extended.2-assets.zip | 完整程序、生产依赖、官方本地素材、11 个场景、官方特效、多语言语音、皮肤和海报 |
| Stronghold-Protocol-v0.3.1-extended.2-lite.zip | 同版程序与生产依赖；不含完整素材，需保留或按部署文档安装 |
| SHA256SUMS.txt / SHA256SUMS.txt.sig | 两个安装包的 SHA-256 清单与 Ed25519 签名 |

**从旧版本控制台首次升级：旧更新器仍只安装程序。升级并重启后，请在更新页面选择当前版本 v0.3.1-extended.2，再执行一次「修复素材并重启」补齐完整素材。** 此操作下载完整包，按差异写入，不是网络增量下载；请等当前对局结束后执行。

也可以停止服务器，将新完整包解压到新目录，保留旧目录并按需迁移设置、记录和内容包。不要用 lite 包替代完整素材包。跨版本恢复快照不保证兼容，升级前应结束活动对局。详见[部署文档](https://github.com/zhewang448/Stronghold-Protocol/blob/v0.3.1-extended.2/docs/DEPLOY.md)。

- 首轮全量 9,000 项：8,949 通过、47 跳过、4 失败；看门狗、Worker 预算与重型 Boss 性能串行复测 48 项通过，打包链接修复后 24 项通过。首轮不表述为全绿，未放宽阈值。
- Windows 相关定向测试 1,203 项（1,199 通过、4 跳过），进程 / 服务 / 启动器集成 72 项通过；更新、签名、素材安装与回滚等专项 83 项通过。不同批次集合有重叠。
- 299 个 golden 全部一致，无基准更新；启动冒烟、lint（0 error，保留既有 warning）、类型与四语言严格检查通过；导入检查退出成功，保留三项既有 Node 专用提示。
- 浏览器验证独立皮肤海报与模型、自选编队保存 / 部署 / 战斗、设置和素材存储；控制台两项连续三轮通过。桌面无头环境不代表真机 Safari 验收。
- 玩法插件局跨服务器重启恢复、最终两回合共享血池回放与部分联动视觉仍有既有边界。本机无头 3D 帧率检查历史上未达到原阈值，可选择 2D 棋盘。
