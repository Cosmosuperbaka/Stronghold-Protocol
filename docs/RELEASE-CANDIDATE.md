# v0.3.0-extended.2 发布说明

状态：**正式版**。基础版本为 0.3.0，上一正式扩展版为 v0.2.6-extended.5。完整素材包与轻量包附 SHA-256 清单和 Ed25519 签名。

## 发布说明

本版将源码更新到上游 0.3.0，保留本库主机控制台、回档、回放、联动干员与皮肤，并完善局内统计和房间交流。

- **局内每回合统计**：交流图标后的统计按钮中切换回合曲线和每回合干员伤害排行；玩家与观战者均可查看，主机默认开启，可统一控制。原有 DPS / HPS 作战统计改为默认开启，可在玩家设置中关闭，保留已保存的关闭偏好。
- **累计与结算查看**：干员排行可以查看单回合或累计至指定回合；战斗中显示各玩家当前回合的实时伤害；结算页和首页对局记录保存回合历史，包含第 15 回合。原有本机 DPS / HPS 作战统计保留。
- **主机消息与屏蔽词**：聊天管理可向当前房间发送主机消息；设置中添加普通文本屏蔽词，忽略大小写，将命中部分替换为 `***`，对之后的玩家和主机消息生效并跨重启保留。
- **主机配置补充**：房间文字聊天开关、单人发言间隔、聊天历史条数、局内实时伤害开关均可保存；实时排行更新不会再打断回合选择。
- **控制台更易查找**：设置按对局、交流、记录与恢复、维护与扩展、清理排列；房间操作分组，对局记录可搜索、每页 20 条，提供本机插件工作台入口。
- **组队海报**：常显更换按钮，可搜索 432 名干员、1,356 张立绘，保存本机并同步队友，与战斗皮肤独立。
- **交互修正**：Q 撤退 / X 出售优先操作点击选中的干员，移到另一名干员上不会改变目标；未选中时保留悬停操作。右键棋盘干员发送标点；不可叠层盟约不再出现在叠层曲线及控制台层数编辑中；改善矮屏创建同盟输入。
- **0.3.0 基础与资源**：保留上游插件基础、官方特效、多语言语音和新增快捷键；完整包同时包含 174 套可选皮肤。素材预载清单与海报目录不再影响玩法指纹。
- **文档与社区入口**：重排 README，补充桌面截图与相关仓库索引，加入 [Forge-Mods](https://github.com/XiaMo233M/Stronghold-Protocol-Forge-Mods)；插件兼容说明见 [COMMUNITY-PLUGINS.md](COMMUNITY-PLUGINS.md)。

## 已知边界与来源

- 原版局保留同版本重启恢复；玩法插件局暂不支持跨服务器重启恢复，需要额外脚本授权的回放暂不播放。
- 第 14、15 回合回放不包含实时共享血池与全队生命同步，尝试播放可能产生不同结果。
- Forge-Mods、Lele 等社区插件依赖各自宿主 API，尚未验证可以直接安装到本库；本版未预装第三方插件。
- 尚未重新测定全地图 3D 帧率，历史无头浏览器性能检查曾未达阈值，可切换 2D 棋盘；完整监控墙未重新跑 30 分钟持续测试。
- 部分联动专属视觉效果与外语文本未完成；本轮 README 仅展示桌面截图，不声称手机真机验证。
- 上游依据为 [sganggs/Stronghold-Protocol v0.3.0](https://github.com/sganggs/Stronghold-Protocol/tree/v0.3.0)；其他来源与许可见 [NOTICE.md](../NOTICE.md)、[LOCAL-CHANGELOG.md](LOCAL-CHANGELOG.md)。本次新增统计与管理功能不修改战斗模拟规则，无新增 `[ASSUMED]` 玩法。
