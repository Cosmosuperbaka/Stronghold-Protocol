# v0.3.1-extended.1 · 跟进上游 v0.3.1

基于上游 v0.3.1（b3deebda），上一正式扩展版为 v0.3.0-extended.3。

## 更新内容

- 接入 Forge 导入、工作台模板、插件交互窗口、干员特质、规则开关、测试房间与测试控制台。
- 跟进联防按实际漏怪波次结算、凯瑟琳突变细胞每人每局一次、琳琅诗怀雅三技能不自动关闭等上游修复，以及官方动作、特效与音效更新。
- 保留主机控制台、回档、回放、融合交流、每回合统计、7 名联动干员、79 名自选池及 174 套皮肤。
- 统一皮肤同步与插件外观；保留随机选择、导入导出、他人皮肤开关与部署缩放默认关闭，恢复皮肤中文名和系列并修复长名称越界。
- 回档恢复交互窗口的抽取次序并拒绝旧时间线请求；测试房间不写入战绩、回放、跨局汇总与重启恢复。
- 移除首页「UI 制作」链接。
- 完整包更新阻隔工事模型，并重新提取 11 个官方战场场景至版本 4，包含无损数据图、发光及重复渲染器修复。
