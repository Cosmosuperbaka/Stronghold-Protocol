# v0.3.1-extended.5 · 手机适配、标点拖动与个人数据迁移

基于上游 v0.3.1，上一正式扩展版为 v0.3.1-extended.4。

## 更新内容

- 修复手机标点栏遮挡队友与底部操作的问题（#10）。标点默认展开，电脑和手机均可手动收起并记忆；支持鼠标、触控拖动、方向键移动、位置恢复与重置。
- 通用手机布局复用参考站已部署规则；房间立绘完整显示，姓名板和列表可滚动，顶部 HUD 按小屏压缩间距。标点图标随现有 rem 缩放，独立触摸区域保持 44px。
- 调整小屏底部工具、交流、详情、作战统计和浮动聊天，按实际视口、安全区与现有控件位置避让；不修改全局缩放或棋盘镜头。
- 每回合统计采用紧凑控件和独立滚动；曲线按可用宽度重画、减少刻度，保留全部数据点与首末回合，触屏可点按查看数值，排行可横滑。桌面与控制台原图表规则保持不变。
- 新增个人数据导出 / 导入、恢复码与备份文件，涵盖本机账号、战绩、编队、皮肤、设置、插件个人配置及自定义背景音乐；导入预览、去重合并与失败回滚。
- 支持旧站授权传输个人数据，并支持部署默认网址预填。旧站无法访问且未事先备份时，无法找回原域名数据。
