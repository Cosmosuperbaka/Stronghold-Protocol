# v0.3.1-extended.4 · 帧率显示、阶段图标与设置交互修复

基于上游 v0.3.1，上一正式扩展版为 v0.3.1-extended.3。

## 更新内容

- 对局延迟旁新增实际 FPS 显示，每秒更新；窄屏在延迟下方排列。设置「帧率上限」下新增「显示帧率」，默认开启，关闭立即生效并保存。简化棋盘或帧率不可用时显示 `-- FPS`。
- 修复联防双图标偏左，以及最终攻势生命值节点、圆环、头像连接线和文字错位；恢复隐秘核心警告图标的完整显示。
- 修复帧率上限选中高亮缺失、手机触摸误选和触屏桌面语音选项跨行覆盖；改善特大字号、背景卡片及屏幕边距调节布局。
- 同盟选择页自定义密钥与创建卡片一起进场；同盟选择、密钥加入和背景设置完善 Tab、Esc、焦点恢复及输入法组字处理。
- S.W.E.E.P. 报告增加退场动画，遵循减少动态效果设置。
- 控制台重复打开同一开发预览时复用页面，Ctrl / ⌘ 点击和中键仍可另开。
- 重新抓取参考站公开前端并记录差异；未引入对方服务器容量与单人保留时限策略。
