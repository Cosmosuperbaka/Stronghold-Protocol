# v0.3.0-extended.3 发布说明

基础版本为 0.3.0，上一正式扩展版为 v0.3.0-extended.2。本版完善交流和工具界面，不修改战斗模拟规则。

## 更新内容

- 局内表情与文字聊天合为同一面板，左栏切换表情和历史、底部单行输入；玩家新文字消息从头像旁显示气泡，保留 200 字、权限、屏蔽词和失败草稿。
- 快捷键移至独立编辑弹窗，保留原键位、冲突交换、恢复默认及 Esc 取消；手机横屏提供可读字号与滚动区域。
- 资源包显示下载字节和速度、整包校验状态、缓存导入文件进度；继续使用原有镜像回退和暂停机制。
- 公告可显式选择 Markdown 长文（最多 20000 字），支持标题、列表、表格、引用、代码和安全链接；纯文本仍为 500 字。长文在弹窗排版，横幅提示点击查看详情。
- 大厅「干员调配」下方新增「统计数据 / LOCAL RECORDS」，打开本库现有统计页面。
- 将结算立绘目录加入对局数据预热，避免自选立绘进入结算后才开始加载。
- 每回合曲线实时更新保留指标选择节点，避免选单在选择时收起；局内和控制台共用修复。
- 跟进 UI 上游的渲染销毁保护、隐藏地面块过滤、皮肤头像及结算立绘、协议独立页、语音多选预载和可选特效分组。
- 增加可选 CDN / R2 同步与资源分包传输，保留本库校验和统一资源 worker；这些部署功能默认关闭。
- 部署时镜头缩放默认关闭，可在设置中显式开启；本次不恢复曾导致比例异常的整体界面缩放。
- 参考来源与适配范围见 [REFERENCE-UI-REVIEW.md](REFERENCE-UI-REVIEW.md)，来源许可见 [NOTICE.md](../NOTICE.md)。

## 来源与已知边界

- 交流与工具 UI 参考 xinhai-ai/Stronghold-Protocol 及参考站当日公开源码，复用本库聊天、统计与资源链路，未引入宣传或付费区域。
- 桌面和手机横屏使用本机 Edge 无头模式验证；不代表真机 Safari、软键盘或刘海屏验收。
- 玩法插件局跨服务器重启恢复、最终两回合共享血池回放与部分联动视觉的既有边界继续存在，见 [LOCAL-DEV.md](LOCAL-DEV.md)。
- 本次无玩法改动，无新增 [ASSUMED] 玩法规则；素材和代码许可见 [NOTICE.md](../NOTICE.md)。
